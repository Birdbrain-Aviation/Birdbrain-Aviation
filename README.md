Hi, I'm Luke. I'm a high school student in Missouri building model and high-power rockets, the flight computers that fly in them, and the software I use to test and analyze them. I'm working toward my NAR Level 1 and want to study aerospace engineering.

### Software

**[Aviary](https://github.com/Birdbrain-Aviation/aviary)**: three desktop apps for my rocketry projects. Owl is a ground station, Heron analyzes flight logs, and Mockingbird tests a flight computer against simulated flights (with faults) before it flies. Windows and Linux, plus an Arduino library for hooking up real hardware.
